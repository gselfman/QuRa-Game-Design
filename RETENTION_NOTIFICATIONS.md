# QuRa — удержание и уведомления v1

**B5; статус:** продуктовые правила утверждены, новые числа — PROTOTYPE BALANCE.

Каналы: Telegram-бот QuRa (основной), PWA push только по согласию. SMS для игровой механики не использовать. Финансовые уведомления не маскировать под игровые.

## Триггеры
| Триггер | Условие | Действие |
|---|---|---|
| DAILY_EVENT | событие дня опубликовано | выбрать из двух вариантов |
| TICKETS_FULL | достигнут лимит 8 | сыграть мини-игру |
| FRIEND_CHALLENGE | вызов от друга | принять Arena 1×1 |
| ASYNC_DEFENSE | защита завершена | посмотреть летопись |
| CHEST_READY | сундук готов | открыть |
| STREAK_RISK | серия под угрозой | мягкое напоминание |
| CLAN_GOAL | близко к цели клана | внести вклад |
| COMMUNITY_GOAL | глобальная веха | открыть прогресс седьмой |
| SEASON | начало/конец сезона | посмотреть сезон |

Событие дня: пример публикации в 10:00 МСК (**PROTOTYPE BALANCE**). Стрик за ежедневный вход / выбор события. Один пропуск за неделю прощается «заморозкой»; параметры стрика и награды **PROTOTYPE BALANCE**.

Частота: не более 2 игровых уведомлений/сутки (**PROTOTYPE BALANCE**), тихие часы 22:00–09:00 по локальному времени (**PROTOTYPE BALANCE**). Cooldown по категории, отдельные подписки и общий opt-out.

## Данные
`NotificationRule` (trigger, channel, template, cooldown, quiet_hours, version), `NotificationLog` (account, dedupe, queued/sent/failed/opened), `StreakState` (day, days, freeze_used). Уведомления не меняют финансовые статусы.

## Метрики
D1/D7/D30 retention, open rate, opt-out, переходы в игру, влияние на реальные подтверждённые операции QuRa.
