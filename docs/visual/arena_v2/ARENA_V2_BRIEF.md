## 2. Противоречия Библии

1. **«Round 1/5» и пять точек.** Бой идёт до выбывания (движок — до 30 раундов), число раундов заранее неизвестно. → «Раунд 3» без знаменателя, точки убрать.
2. **Нет таймера хода 45 с** (§30.2, Молния богов). Это обязательный элемент живого боя. → кольцо таймера вокруг центральной кнопки.
3. **AUTO.** Автобой по §30.8 — платный тактический сервис на **один ход**, в прототипе не реализуется. Галочка «авто на весь бой» противоречит правилу. → убрать из панели.
4. **▶▶ ×2 (ускорение).** Бой пошаговый с одновременным скрытым выбором, проигрывать быстрее нечего; ускорение анимаций раскрытия ломает темп живого боя для второго игрока. → убрать.
5. **✕ над «Round».** Выход из боя = поражение; один тап по центру шапки — риск случайного нажатия. → выход только из меню ≡ с подтверждением «Сдаться?».
6. **Шапка «Team QuRa ★2845 / Rival ★2831».** Английский текст; непонятно, что за ★. → имена игроков; число — Боевая сила (БС) с иконкой ARN02; рядом значок **Боевого духа** (±%), который по §25 соперник обязан видеть.
7. **Одетые курочки.** §43.1 п.2 (LOCKED): курочка игрока выглядит так, как она одета в Гардеробе. Новый арт — цельные картинки «в костюме основательницы». См. решение Р-3.
8. **Подсказка действия.** §44.2 — карточка с 5 блоками, открывается тапом. Владелец 07.11: карточка мешает. → заменить всплывающей подсказкой (Р-2).
9. **Бот** подписывается «<Тип> · бот» (§44.1), в макете просто «Боевик».

## 3. Чего не хватает

- **Таймер хода** (см. выше).
- **Бафы в бою** — до 3 расходников на бой, 1 за раунд (§26.2). В макете негде их активировать.
- **Выбор цели** в режиме «Выбор цели» (§43.4): тап по курочке соперника, стрелка от своей к цели.
- **Кто уже выбрал ход** в 2×2/3×3: маленькая иконка выбранного действия над плашкой своей курочки, «2 из 3».
- **Щит и активные бафы** — иконки в плашке (§47.5).
- **История боя** (§44.3) — открывается из строки журнала (уже есть место).
- **Подсказка / Ясновидение** (§30.5) — бесплатно в прототипе.
- Ожидание соперника после своего хода: «Соперник выбирает…».

## 4. Нижняя панель — что ставим вместо AUTO / ×2 / ••• / i

```
[ Атака ] [ Защита ] [ Манёвр* ] [ Особый* ]      * имя и иконка приёма выбранной курочки
[ Бафы 3 ]   [ ((  ХОД!  )) ]   [ Подсказка ]     кольцо = таймер 45 с
[ ≡ журнал · чат: «Раунд 3 · Ряба Атака / Боевик Защита» ……… ^ ]
```

- **Центр — «Ход!»** (большая золотая кнопка, бывший ▶). Фиксирует выбор на раунд. Вокруг — кольцо таймера 45 с; последние 10 с — красное с пульсом. До выбора действия серая. В 2×2/3×3 активна, когда у всех живых курочек есть действие (и цель, где нужна).
- **Слева — «Бафы»** (бывшее •••): иконка сумки со счётчиком оставшихся (до 3). Тап — лента бафов над кнопками, тап по бафу — подсказка, повторный тап — применить к выбранной курочке.
- **Справа — «Подсказка»** (бывшее i): совет на этот ход по открытым данным. Позже — платная (§30.5).
- **AUTO, ×2 — убрать.** Автобой появится позже как платный баф в ленте бафов, не отдельной кнопкой.

## 5. Как работает выбор действия (решение владельца 07.11)

1. **1×1:** иконки Манёвра и Особого сразу личные (Скорлупа / Золотая скорлупа и т. д., §44.2).
2. **2×2 / 3×3:** пока курочка не выбрана — общие иконки «Атака, Защита, Манёвр, Особый». Тап по своей курочке (или по её плашке) — она подсвечивается, Манёвр и Особый меняются на её личные.
3. **Тап по действию** = выбрать (можно переиграть до «Ход!»). Над панелью на **2 секунды** всплывает подсказка: название приёма + эффект для этой курочки сейчас + одна строка «бьёт Манёвр, проигрывает Защите». Без кнопок, исчезает сама, следующий тап её заменяет.
4. Полная карточка §44.2 — только по **долгому нажатию** на действие (для тех, кто хочет читать).
5. В «Выборе цели» после атакующего действия — тап по противнице, появляется стрелка.
6. Особый до 100 заряда — серый; тап по серому показывает подсказку «Нужно 100 заряда, сейчас 64».

## 6. Путь игрока (что редизайним)

1. **Ворота Арены** (тап «Арена» в меню): главная курочка анфас (`hens_front`), БС, Слава, Боевой дух, статус Обороны, одна кнопка «В бой». Если Обороны нет — сначала Оборона (§43.3).
2. **Формат** — три большие плитки 1×1 / 2×2 / 3×3 с превью арены (сарай / двор / колизей). Закрытые — замок и «Нужна ещё 1 курочка L4».
3. **С кем** — плитки: Бот (бесплатно), Соперник (аренда 10 GE, сундук), Друг. Для команд — ещё «Стенка на стенку» / «Выбор цели» с мини-схемой.
4. **Расстановка** — поле выбранной арены с местами 1–3, внизу карусель своих курочек анфас (имя, уровень, БС). Тап по курочке → на ближайшее свободное место; перетаскивание между местами. Сумма БС команды. Ниже — выбор до 3 бафов в бой.
5. **Против** — две стороны, БС, Боевой дух, цена аренды и приз (раскрыть до списания, §30.6), «В бой».
6. **Бой** — макеты владельца с правками §2–§5.
7. **Итог → Летопись** — без изменений, кроме стиля кнопок.

Звуки боя — прежние (§47.5, `docs/audio`).

- **Р-1. Перейти на новый стиль курочек в Арене** (боевая стойка в профиль). Рекомендация: да; Курятник остаётся уютным.

- **Р-3. Как показывать вещи на боевых курочках.** Варианты:
  - (а) в Арене курочка всегда в «форме основательницы» как на листе, надетые вещи — иконками в плашке и в «Против». Быстро, без новой отрисовки. Нарушает §43.1 п.2 только в Арене.
  - (б) дизайнер рисует для боевой позы голое тело 6 курочек + слои 35 вещей (как v12 для Курятника). Честно, но это ~2–3 недели арта.
  - Рекомендация: **(а) сейчас, (б) позже** задачей дизайнеру.
- **Р-4. Убрать AUTO и ×2; поставить Бафы / Ход с таймером / Подсказку** (§4). Рекомендация: да.
