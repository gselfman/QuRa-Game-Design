## Техническая схема сборки

Порядок определяется частями, а не единой иконкой: задние ремни/шляпа → чистое тело → жилет и пояс → передние крылья → передняя сумка → шейный предмет/лицо → очки → передняя шляпа/маска гребня → FX. Нельзя применять этот порядок ко всему исходному плоскому PNG без подготовки частей.

Весь комплект привязывается к одному root CARD. Эмоции не меняют тело, голову и attachment points. При runtime наклоне поворачивается собранный персонаж целиком. Никаких генераций боевых поз.

## Следующий фактический этап

1. Подготовить чистую базу из подтверждённого master: убрать шляпу, бусы, пояс и сумки; восстановить скрытое оперение и причёску, не меняя видимых лица, хвоста, крыльев и лап.
2. Отдельно сохранить default-аксессуары и occlusion masks. Проверить обратную сборку исходного вида.
3. Примерить пять подготовленных overlay-предметов по одному, затем вместе; проверить в 512/256/128 px. Приёмка схем не является приёмкой будущих растров.
4. Верифицировать точные опорные точки на чистой базе; текущие векторные контуры — только руководство художнику.
5. Только после проверки переносить процесс на PERCH/NEST и остальные героини.

Чистая база, точные маски и реальные примерки в этом шаге не созданы. Новых изображений не генерировалось.
