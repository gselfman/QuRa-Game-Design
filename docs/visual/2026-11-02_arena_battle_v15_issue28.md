## Что изменено

- Меню: видимая графика иконок около 40 px вместо прежних маленьких изображений; в бою скрыто. Нижняя зона свайпа/кнопка открывает меню, после боя меню показано. Есть отдельные состояния меню для 1×1, 2×2 и 3×3.
- Атака и Защита используют общие готовые картинки. У каждой из шести курочек — свои Манёвр и Особый из существующих спрайтов. 14 всплывающих описаний объясняют эффект, ограничения и ответы соперника.
- Действия расположены выше свёрнутого чата. Есть раскрытый чат, отправленное сообщение, чат лобби и чат результата. В тренировке — системные сообщения.
- Под каждой табличкой видны HP и заряд Особого. До 100 кнопка серая; при 100 полноцветная и светится. Урон, рост заряда, появление эффектов и подсветка табличек анимированы. Фигуры не окрашиваются зелёным/красным.
- Оба выбранных действия раскрываются вместе с эффектами. История вызывается из левой зоны свайпа вправо и кнопкой «История». В финале — литературная летопись, изображение конкретного момента и Share.
- Для 2×2 и 3×3 показаны «Стенка» и «Выбор цели», с ботами, подбором и другом для каждого сочетания. В Стенке у каждой курочки свой противник; в свободной цели цель выбирается для конкретной курочки.
- 3×3: один боец впереди, два позади; у головы фиксируется иконка выбранного действия. Есть выбор первой/второй/третьей курочки и состояние 3/3 подтверждённых действий.
- Бафы: пояс, описание, допустимая цель, подтверждение, активный эффект, ограничение на раунд и недоступная «Двойная сила». Показаны Неуязвимость, Последнее перо, Купол, Заряд и Обмен местами.
- Тактика: Подсказка, Автобой, Всевидящий с 16 рассчитанными сочетаниями и риском двойного KO. Разведка заблокирована онлайн; отдельно показан будущий асинхронный сценарий раскрытия одного защитника.
- Арены: 1×1 — исходный Курятник; 2×2 — Птичий двор с соломой, забором, сеном и зрительницами; 3×3 — Колизей с соломой и трибунами. В боях используются существующие determination/злые лица.

## Сохранение существующего дизайна и аудит

Визуально просмотрены 20 существующих атласов; учтены 435 зарегистрированных элементов. В новых экранах фактически используются 29 нормализованных боевых спрайтов и 46 исходных компонентов, все шесть примерок CARD владельца и шесть готовых злых эмоций. ARN01, ARN02, токены, типографика, одежда, сумки и шляпки переиспользованы. Исходные утверждённые страницы и оригиналы не перерисованы.

Для чужих игровых контекстов — награды, сундуки, мини-игры, мебель, жизненные стадии — ассеты сохранены в каталоге, а не добавлены в боевой HUD. Полная таблица по каждому элементу: [audit JSON](manifests/2026-11-02_arena_sprite_audit_v15.json). AEX01 содержит референсы гладиаторских скинов, а не готовую зарегистрированную одежду: новые костюмы поверх исправленных примерок не нарисованы.

Сгенерированы только два недостающих фона через Figma AI; использованы Figma AI credits. Это новые варианты на утверждение владельцем. Изображение летописи собрано из реальных участников, готового фона и существующего эффекта соответствующего действия.

## Механика и демонстрационные данные

Источники: `ARENA_SPEC_V1.md`, `BUFF_CATALOG.md`, `CHICKEN_CATALOG.md`, `tools/arena-engine.mjs`, `arena-live-3x3/team-core.js` и v13 sprite/emotion manifests из main `0e80c904e9c842fab82868b0317ac74734787c8e`. Приоритет — Arena Spec; численные примеры относятся к PROTOTYPE BALANCE.

Основная 1×1 цепочка рассчитана исходным движком: раунды `Атака/Защита`, `Манёвр/Манёвр`, `Атака/Защита`, `Манёвр/Манёвр`, `Особый/Защита`, `Защита/Защита`, `Защита/Защита`, `Защита/Атака`, `Особый/Манёвр`. После Р4 HP 52/50, заряд 100/100; после Р5 HP 52/39, щит Рябы 14; после Р9 HP 51/0. Летопись содержит эти факты. Переход «К финальному раунду» пропускает промежуточные раунды в кликабельном демо; они присутствуют в истории.

Все четыре вкладки Всевидящего рассчитаны для Рябы 52 HP и Боевика 50 HP при 100/100 энергии. Отдельный пример при 10/10 HP показывает двойной KO. Скрытый фактически выбранный ход живого игрока не читается. Командные HP/заряд на раскрытии взяты из расчёта соответствующего типа боя, без выдуманного одинакового урона всем.

## Переходы

| Вход/действие | Что открывается |
|---|---|
| 1×1 → картинка Манёвра → подтвердить | Ожидание → раскрытие Р4 → Особый готов |
| Особый готов → картинка → подтвердить | Эффект Р5 → финальный Р9 → летопись → Share |
| Нижняя зона, свайп вверх / «Меню» | Крупное меню текущего формата; можно скрыть |
| Левая зона, свайп вправо / «История» | История текущего формата → возврат в бой |
| Свёрнутый чат | Развёрнутый чат → сообщение → свернуть |
| Пояс бафов | Каталог → эффект/условия → цель/подтверждение → статус |
| Тактика → Всевидящий | Вкладки своего действия → четыре ответа соперника → риск KO |
| Тактика → Разведка | Блокировка онлайн → отдельный async-сценарий → защитник → раскрытый ход |
| 2×2/3×3 → тип боя → способ запуска | Боты → тренировка; подбор → лобби; друг → приглашение → лобби |
| Свободная цель 3×3 | Действие Рябы → противник → Профессор → Монах → 3/3 → раскрытие |
| Стенка | Закреплённые пары → выбранные действия → раскрытие каждой пары |

## Проверка и пределы прототипа

- 262 экранов; 2194 действующих реакций, включая 192 drag-жеста. Целей на удалённые узлы не найдено.
- 160 анимированных узлов, 206 дорожек. [MP4 раскрытия раунда](https://github.com/gselfman/QuRa-Game-Design/blob/design/28-arena-flow-v14/assets/screens/arena_battle_v15/v15-round-motion.mp4) экспортирован из Figma и проверен по началу/окончанию: HP уменьшается, заряд растёт, таблички светятся.
- Только Onest и Russo One; отсутствующих шрифтов нет. Модальные окна вмещают описания и кнопки; сценарии проверены в обоих размерах. UI состоит из редактируемых слоёв и инстансов, а не скриншота интерфейса.
- Это макет и Figma-прототип фиксированных сценариев, не работающий клиент игры. Backend, реальные уведомления, платежи, отправка сообщений и системный Share/copy не выполнялись.
- Figma On Drag использует отдельные нижнюю и левую зоны. Направление «вверх»/«вправо» — часть спецификации реализации; клик служит альтернативой.
- На границах существующих страниц v14/native используется ссылка в их Figma-прототип. Это сохраняет утверждённые экраны; внутри v15 переходы обычные.
- Точные величины ряда бафов, цены услуг в GE, ranked allowlist и окончательные лимиты остаются OPEN в продуктовой спецификации. Макеты не меняют эти решения. Пояс на три предмета использует существующую рабочую гипотезу.
- Разведка в асинхронном бою — предложение будущего интерфейса на утверждение; в синхронном режиме показан запрет. Всевидящий не раскрывает выбранный ход.
- «Все форматы открыты» — отдельный пример аккаунта с тремя взрослыми курочками уровня 4. В исходном сценарии с одной курочкой блокировки 2×2 и 3×3 сохранены.

Дизайн готов к утверждению владельцем.
