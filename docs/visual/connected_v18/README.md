## Что передаётся

- Единая страница с 527 состояниями и 7906 реакциями. Перенесены готовые экраны приглашений, боёвки и исключений; сохранены утверждённые ассеты, персонажи, шляпы, сумки, эмоции и стилистика QuRa. 477 прежних входов в прототип направлены в соответствующие актуальные экраны. Оригинальные пиксели на предыдущих страницах сохранены.
- Курятник: курочки сидят на жёрдочках, крупное меню соответствует Арене. Тап по жительнице открывает её карточку; доступны имя, гардероб, снятие и возврат комплекта. Сбор пассивной награды связан с балансом, дневным заданием и состоянием повторного сбора.
- Перед Ареной: отдельная настройка Обороны, пустые силуэты мест, окно выбора из шести курочек, запрет дубликатов, замена и удаление. Раздельные составы 1×1, 2×2, 3×3; подтверждённая Оборона хранит состав, стратегию и бафы независимо от последующего черновика.
- Перед первым входом в Арену требуется сохранить Оборону. Три стратегии: Агрессивная, Осторожная, Хитрая. Есть пауза и возобновление подбора, журнал защиты, скрытая и раскрытая Разведкой расстановка противника.
- В бою состав копируется из расстановки один раз. Выбирается собственная курочка, её действие, а в «Выборе цели» — противник тапом по фигуре или HP-панели. Можно сменить цель до подтверждения. Защите цель не нужна. В «Стенке» пары мест закреплены: 1—1, 2—2, 3—3.
- Манёвр и Особый используют уникальные существующие картинки каждой из шести курочек. Окно эффекта показывает выбранную картинку, описание и условия. Особый зависит от энергии выбранного бойца. Ходы сохраняются отдельно, сводка позволяет изменить выбор, после отправки редактирование закрывается.
- Меню вызывается снизу тапом или свайпом вверх; история — кнопкой либо свайпом вправо с левого края. Действия находятся выше свёрнутого чата. Чат открывается до, во время и после боя, возвращается в предыдущий контекст. Локальный ввод поддерживает русскую/английскую раскладку, регистр, пробел, очистку и стирание. Пустая отправка неактивна; настройка отключения чата учитывается.
- Для 2×2 и 3×3 сохранены оба типа боя и все способы запуска: боты, подбор, друг. Результат, летопись и Share возвращаются к своему формату. Расстановка Колизея следует ручному эталону владельца; таблички стоят напротив соответствующих курочек.
- Добавлены назначения отсутствовавших разделов меню: задания/Путь, ресурсы GE, билеты, игровые настройки, аудиотека, карточки и гардероб. Внешние мини-игры открывают существующие приложения QuRa; их утверждённые графика, движок и звук не заменены.

## Основные переходы

| Действие | Результат и возврат |
|---|---|
| Курятник → Арена при несохранённой защите | Первый вход → Оборона → состав/стратегия/бафы → сохранить → подготовка |
| Формат 2×2 / 3×3 | Тип боя → силуэты расстановки → выбрать курочек → способ запуска |
| Подбор противника | Поиск → скрытая защита → опциональная Разведка → условия аренды → бой; отмена до подтверждения |
| Друг | Способ приглашения / партнёры / email / ссылка → доставка/исключение → лобби с чатом → готовность → бой |
| Действие курочки | Описание эффекта → цель при необходимости → подтверждение → следующая курочка → сводка → фиксация |
| Собственная фигура / HP-панель | Выбор курочки для её индивидуального хода |
| Фигура / HP противника | Выбор либо смена живой цели в свободном типе боя |
| Чат / клавиатура | Ввод → Готово → локальный черновик → отправка → локальное сообщение; свернуть → предыдущий экран |
| История / тактика / бафы | Соответствующий раздел → возврат к текущей команде; синхронная Разведка заблокирована |
| Финал → летопись → Share | Передача/копирование → летопись своего формата, без перехода в посторонний бой |
| Собрать | 4 GE в основном демонстрационном Курятнике → 1234 GE, 0/4 → повторный сбор показывает «Всё собрано» |
| Игры | Действующие `qura.one/gamezone/volk` и `/poultry`; открытие меню не списывает билет |

## Проверка

В [qa/v18-checks.json](qa/v18-checks.json) — 12 успешных проверок актуальных реакций: снимок состава, личный Манёвр и цель, Защита без цели, фиксированные пары, доступность Особого, фиксация всей команды, другая курочка в 1×1, защита от повторного сбора, существование назначений, выходы, шрифты и целостность аудио. Ещё 13 проверок состава и Обороны — [qa/prototype-checks.json](qa/prototype-checks.json).

В [qa/v18-control-audit.json](qa/v18-control-audit.json) нет активных кнопок без реакций. Исключены скрытые/неактивные состояния, иллюстрации выбранного действия и фон под модальным окном. В [navigation.json](navigation.json) нет отсутствующих внутренних целей; каждое состояние имеет путь возврата или предусмотренный внешний выход. Используются только Onest и Russo One.

Метод проверки: чтение фактических Figma-реакций через Plugin API и их локальное исполнение моделью состояний. Проверены визуальные контрольные листы обоих размеров. WebP экспортированы без потерь и сравнены с PNG по пикселям. Это не отчёт о ручном прохождении в браузере: Figma в облачном браузере вернула 403. Статические контрольные листы показывают исходные значения переменных; состав и выбранные команды следует проверять запуском от входного экрана.

## Звук

[Аудиодемо — скачать и открыть HTML](../../../assets/audio/v18/listen.html) · [Курятник, MP4](../../../assets/audio/v18/preview-coop.mp4) · [Арена, MP4](../../../assets/audio/v18/preview-arena.mp4) · [Эффекты, MP4](../../../assets/audio/v18/preview-sfx.mp4)

Две оригинальные музыкальные петли и 33 эффекта, без сторонних сэмплов: OGG для музыки, FLAC-мастера, WAV для эффектов. [Манифест](../../../assets/audio/v18/audio-manifest.json) содержит события, длительности, SHA-256, пики и параметры микса; [привязка к экранам](audio-events.json) — состояния и события реализации. Музыка по умолчанию 25%, эффекты 70%, до четырёх одновременных эффектов, приглушение на сообщение, плавная смена сцены, уважение mute и первого действия пользователя.

**Нативное воспроизведение звука внутри этого Design-прототипа недоступно через текущий редактор.** Code Layers для файла отключены, API создания видео не поддерживается. Настройки и кнопки прослушивания работают, но автоматический игровой микс должен подключить разработчик. MP4 и автономный HTML уже содержат воспроизводимое аудио; не считать его встроенным в Figma.

## Границы реализации

Это дизайн и интерактивный UI-прототип. Локальные сообщения не отправляются другим людям, аренда не списывается, приглашения и Share не рассылаются. Подготовка, выборы, цели, сводка, сохранение Обороны и настройки имеют состояние. Утверждённые раскрытия раундов, численные результаты и летописи остаются демонстрационными ответами; они не являются полным BattleEngine для любой комбинации состава, бафов и действий. При разработке раскрытие обязано строиться из фактически зафиксированных snapshots и команд сервера; нельзя подменять выбранный ход образцом.

2×2 и 3×3 отрисованы полностью как UX, но их выпуск регулируется feature flags и roadmap. Цены и параметры, помеченные в концепте PROTOTYPE BALANCE, не утверждаются этим handoff. Лимит/приоритеты бафов, тарифы сервисов, правила прогрессии и backend-экономика не менялись. Новое решение владельца о раскрытии расстановки Разведкой — расширение async UX; оно не разрешает читать скрытый живой ход.

Источник требований: `GAME_BIBLE_V1.md`, `SCREENS.md`, `ARENA_SPEC_V1.md`, `BUFF_CATALOG.md`, `QUEST_CATALOG.md`, `EVENT_CATALOG.md`, `ASSET_PRODUCTION.md` и прямые замечания/согласование владельца. Пассивное золотое яйцо — GE, а не вторая валюта; билеты +2/сутки, максимум 8, один на призовую попытку мини-игры. Последнее перо использует S04_02; S04_03 — Феникс. Наследованный ключ выбора `S04_03` в некоторых переменных Обороны означает Последнее перо и требует семантического переименования при реализации.

Production-код не изменён. PR агентом не объединяется. Передача разработчику продолжается в существующих [UI issue #60](https://github.com/gselfman/QuRa/issues/60) и [Оборона issue #70](https://github.com/gselfman/QuRa/issues/70); этот экспорт заменяет ожидание handoff в их предыдущих описаниях.
