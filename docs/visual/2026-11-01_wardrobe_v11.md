# QuRa wardrobe v11 — complete independent clothing

The v09 garment extractions retained holes where bags and shoulder straps covered the original image. All six clothing layers now use complete garment sources from the existing wardrobe and catalogue. The same garment component is used in the full outfit and in the clothing-only proof, so removing bags and straps no longer exposes those cutouts.

## Deliverable and validation

35 equipment groups, 77 separately registered full-outfit layers, six complete garments and 12 standing assemblies: six full outfits plus six clothing-only proofs. Base heads and bodies retain the existing artwork; no new hens were generated.

All six garment PNGs and twelve composite PNGs were checked as 1200 × 1520 RGBA with transparency and the shared origin. Both native Figma boards were exported and visually inspected. The full and clothing-only instances were checked against the same garment component for all six characters.

Alpha and depth clipping are baked into individual sprite files, retaining separate selectable layers and avoiding reliance on Figma vector-mask export behaviour.

## Reproduction

Install `tools/art/wardrobe-v11/requirements.txt`. Set `QURA_BASE_DIR` to extracted v08, `QURA_ACCESSORY_DIR` to extracted v09 and `QURA_WORK_DIR` to a work directory containing `eye-pins.json` and `anatomy-map.json`.

Run `build_tryon.py`, then `build_complete_clothing_v11.py`. The second step replaces the intermediate garment layers with the complete sources and renders both proof modes. `apply_complete_clothes_v11.js` records the Figma update against the known existing six rigs. Manifests record source paths, fitted layers, component IDs and verification results.
