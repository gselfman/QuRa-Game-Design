# QuRa M2/M3 — план поведенческого симулятора

## Архитектура
`tools/ge-economy-simulator.mjs` — статические GE и цены; `tools/behavior-simulator.mjs` — XP/стадия, уровень, поведенческий цикл одного пользователя и 3 исследовательские когорты; `tests/behavior-simulator.test.mjs` — детерминизм и инварианты.

## M2 (модель-прототип)
- XP L1–L20 согласно START_BALANCE_CONFIG_V0.
- L1/L2: яйцо, L3: цыплёнок, L4+: взрослая; минимум 1 GE/сутки с L3.
- До 4 бесплатных боёв с ботом за активные сутки с L4, никаких списаний/реальных выплат.
- 30-дневные сценарии explorer, wallet, gamer с seeded RNG.
- Оценочные вероятности не являются измеренным удержанием пользователей QuRa.

## M3 следующие работы
1. Multi-chicken roster, свободные места 2/4/6/10/16/24, покупка обычных инкубационных яиц.
2. Выбор первой основательницы, milestone 2-й/3-й и XP распределение между курочками.
3. Покупки SKU, GE sinks, платные бои 3 GE после 4 бесплатных, caps.
4. Monte Carlo с percentiles и сравнениями конфигов.
5. Админка с конфигурационным diff, прогнозом time-to-goal и аудитом.
6. Интеграционные тесты событий кошелька без копирования реальных финансовых операций.

## Запуск
Node 20+: `node --test tests/behavior-simulator.test.mjs`.
Демонстрация: `node tools/behavior-demo.mjs`.

**Ограничения:** эти файлы — новая автономная исследовательская реализация M2, а не побайтовая копия ранее созданного ZIP. Финансовый backend и production не меняются.
