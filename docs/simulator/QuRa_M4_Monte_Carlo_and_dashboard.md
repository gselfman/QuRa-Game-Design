# QuRa M4 — массовая симуляция и сравнение баланса

**Статус:** исследовательский прототип, код в `main`; автоматический запуск тестов и UI не подтверждены, production QuRa не изменён.

## Состав
- `tools/farm-monte-carlo-m4.mjs` — массовые воспроизводимые прогоны M3, перцентили, показатели цели и разница конфигураций.
- `tools/farm-m4-cli.mjs` — командная строка, экспорт JSON/CSV.
- `tests/farm-monte-carlo-m4.test.mjs` — 9 тестов статистики и инвариантов.
- `m4-dashboard/index.html` — интерактивная версия с изменением ставки GE уровня L10 и сравнением.
- `tools/m4-baseline.example.json` и `tools/m4-candidate.example.json` — примеры JSON-конфигураций.

## Использование локально
Из корня репозитория, Node 20+:

```bash
node --test tests/ge-economy-simulator.test.mjs tests/behavior-simulator.test.mjs tests/farm-simulator-m3.test.mjs tests/farm-monte-carlo-m4.test.mjs
node tools/farm-m4-cli.mjs --users 300 --days 90 --seed 20261030 --out m4-results
node tools/farm-m4-cli.mjs --users 1000 --days 90 --seed 20261030 --config tools/m4-baseline.example.json --compare tools/m4-candidate.example.json --out m4-compare
python3 -m http.server 4173
```

После запуска локального HTTP-сервера открыть `http://localhost:4173/m4-dashboard/`. Нельзя открывать HTML через `file://`, поскольку используются ES-модули.

## Входные параметры
`users` (1–100000), `days` (1–3650), `seed`, `cohortWeights` (explorer/wallet/gamer), `overrides` — параметры уже поддерживаемые `simulateFarm`: `startingXP`, `startingGE`, `capacity`, `policyOverrides`, `rateOverrides`, `grantMilestones`. Выравнивание seed между baseline/candidate снижает шум.

## Отчёты
- Показатели `level`, `geBalance`, `geEarned`, `geSpent`, `chickens`, `gear`, `logins`, `walletActions`, `botBattles`.
- `mean`, P25, P50, P75, P90.
- День достижения L3/L4/L6/L10, второй/третьей курочки и первой покупки экипировки; доля достигших учитывается от ВСЕХ участников, а перцентили дней — только от тех, кто достиг.
- Сумма GE по источникам и sinks.
- CSV по пользователям в одиночном прогоне; JSON в сравнительном.

## Ограничения
- Никаких реальных пользователей, платежных событий или retention-данных; вероятности поведения — искусственные гипотезы.
- M3 ещё не моделирует полный магазин/развитие, опции цен, реальные GE пакеты, подписки, платные бои за 3 GE, реальную главу «Хозяйство» и формальные XP caps. Изменить цену стандартного яйца в M4 можно будет после параметризации M3, **пока не обещать эту настройку**.
- Важное ограничение: метрики удержания `logins` лишь результат заложенных вероятностей, нельзя считать их прогнозом реального D1/D7/D30.
- Высокое число пользователей может блокировать браузерный интерфейс; для тяжёлых прогонов использовать CLI.
- Минимум 1 GE/сутки с L3 — LOCKED; значения выше — PROTOTYPE BALANCE.
- GitHub Pages до этого не проходил шаг `Configure Pages`, поэтому наличие HTML в репозитории **не означает опубликованную страницу**.
