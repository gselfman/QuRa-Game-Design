# Задание агенту: следующий шаг — баланс Arena по целям
**Репозиторий:** https://github.com/gselfman/QuRa-Game-Design · **Дата:** 30.10.2026
**Файл:** docs/instructions/2026-10-30_next_step.md

Экономические симуляторы M1–M4 заморожены: моделирование поведения игроков основано на допущениях. Главная задача — баланс Arena. Агент самостоятельно подбирает PROTOTYPE BALANCE — подобрано симуляцией vX, обращаясь к владельцу лишь при доказуемо несовместимых целях. Выполнять строго T1→T2→T3→T4→T5→T6→T7, один PR на задачу.

## T1 — CI
Создать GitHub Actions `tests.yml` (Node 20, `node --test tests/` для push и PR); исправить обнаруженные ошибки; зафиксировать ссылку на **зелёный запуск в main**. Без него следующие задачи не считаются выполненными.

## T2 — Battle Engine
Вынести чистое детерминированное ядро из `arena-live-3x3/team-core.js` и `arena/index.html` в `tools/arena-engine.mjs`. Включить четыре действия, контр-матрицу, HP/щит/лечение/заряд, шесть Special, «Стенка» и JRPG, единый движок прототипа (ARENA_SPEC §60). Стратегии: random, greedy и equilibrium — смешанная 4×4 матричная стратегия; три defensive AI. Оценивать equilibrium vs equilibrium. CLI: 6×6, минимум 10 000 боёв на пару, fixed seed, CSV/JSON. Тесты детерминизма, HP≥0, charge 0–100, отсутствия действий погибшего, parity с прототипом.

## T3 — правила боя
Проверить варианты и выбрать согласно целям, внести данные и LOCKED по симуляции vX в ARENA_SPEC и ARENA_SIMULATION_RESULTS: Speed (последовательный/одновременный; предпочесть одновременный), multi-collision once/per-collision, JRPG retarget (потеря/автоцель/одновременность), таблицу charge, ничьи/двойной KO и тай-брейк если >2%.

## T4 — баланс цифр
Подобрать стартовые L4 статы всех шести, уровень→статы (+1/+4), Maneuver/Special, регрессию BP→win% и веса BP, 38 предметов G01/G02, BP допуск async. Перенести в START_BALANCE_CONFIG v0.2, GEAR_CATALOG, ARENA_SPEC и ARENA_SIMULATION_RESULTS. Все метрики в коридоре целей.

## T5 — асинхронные тактики
Подобрать агрессивную, осторожную и хитрую защиту; проверить attacker 50–60%, лучший exploit ≤70%, при необходимости добавлять случайность.

## T6 — прогресс по M4 без развития M4
Прогнать существующий M4 (1000 пользователей, 90 дней, wallet), сверить цели; при необходимости корректировать лишь XP по источникам и milestones. Сохранить «цель/факт» в ECONOMY_CALIBRATION_2026-10.md и отметить гипотетичность поведенческих вероятностей.

## T7 — порядок в GitHub
Удалить слитые docs/fix-2026-10-29-* и docs/pass2-* ветки; сохранять задания в docs/instructions/, обновить DOCUMENTATION_INDEX; напомнить владельцу Settings → Pages → Source: GitHub Actions.

## Итоговый отчёт
Ссылка зелёного CI; матрица побед 6×6 и все цель/факт; пять решений T3 и обоснования числами; все изменённые величины до→после; только доказанные конфликты целей и компромиссы.

## Запреты
Никаких M5, никаких изменений production QuRa; сохранять минимум 1 GE/сутки с L3, D-19, D-20, 4 бесплатных боя с ботом и следующие за 3 GE, аренду Arena. Не выдавать вымышленные удержание/конверсию за факты. Задача не завершена без зелёного CI.
