## План воспроизводимого расчёта
- A/B модели Speed (последовательное против одновременного исполнения).
- Wall 1×N: один выбор, self heal/shield/charge раз за действие, target damage за столкновение — варианты OPEN.
- JRPG death retarget: lost action / auto-target / simultaneous.
- Charge: победа, поражение, ничья, Defense, 1×N.
- BP weights: marginal win-rate +1 HP/ATK/DEF/SPD.
- 1×3 comeback, first-round focus fire, средняя длительность.

Для каждого сравнения использовать фиксируемые seeds и минимум 10000 боёв на matchup (**PROTOTYPE BALANCE**). Сохранять конфиги, CSV результатов, ошибку оценки. Только после этого решать OPEN.
