## Статус

Это подробный проект для реализации, **не готовая игра**. Правила, прямо заданные владельцем, помечены LOCKED; предложенные численные значения — PROTOTYPE BALANCE; непроверенные зависимости — OPEN. Ни наличие документа, ни размещение в Figma не означают утверждение новых моделей, запуск игры или выдачу реальных наград.

Два обязательных исправления относительно первых картинок:

- Персонажи — реальные образы QuRa из существующей библиотеки; новые случайные курочки запрещены.
- Увеличение применяется только внутри оптической линзы. Основная камера не приближает всё окружение. Перекрестие находится в центре линзы, мишень подводится под него наведением оружия.

## Проверка пакета

Из каталога репозитория: `python3 games/kuro-sniper/tools/validate_bible.py`.

Проверяются десять уровней, 46 раундов, пять игровых архетипов, ссылки на оружие и промпты, арифметика патронов, геометрия оптики и внутренние ссылки документации. Это проверка проекта и данных, не доказательство производительности или качества ещё не созданной игры.
