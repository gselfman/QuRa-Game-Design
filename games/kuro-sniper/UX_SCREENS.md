# Интерфейс, управление и экранные состояния

> Дополнение v0.2 от 15.11.2026: [текущие решения, реализованное и оставшееся](VISUAL_AUDIO_V02.md). Оно заменяет прежние значения воды, расположение кнопок, оружие второй дистанции и добавляет десятый уровень.
## 1. Система и стиль

Основной формат — landscape, базовый макет 844×390 CSS px, проверки 740×360, 932×430 и 1024×768 с игровым viewport. UI масштабируется от CSS-размеров и safe-area, не от физических пикселей. На планшете свободное место расширяет мир, а HUD остаётся у безопасных краёв.

Шрифт интерфейса Onest, заголовки Russo One согласно существующим экранам QuRa; файлы шрифтов и право распространения сверить при реализации. Дерево и золото — небольшие обрамления, без тяжёлых непрозрачных рамок на поле зрения. Белый основной текст, янтарные очки, мятный пульс, голубое дыхание, коралловый штраф. Контраст обеспечивается тёмной полупрозрачной подложкой, цвет дублируется значком/числом.

Основной текст 14–16 CSS px, подписи не меньше 12. Основные touch targets 56–64 px, вспомогательные минимум 44 px с 8 px промежутка. UI занимает края; центральная область вокруг мишеней свободна. Не размещать системно важную кнопку в зоне выреза или домашнего индикатора.

## 2. HUD, одинаковый во всех комплектах

| Зона | Элемент | Обновление |
|---|---|---|
| Сверху слева | Уровень N/10, раунд R/5 | Только на переходе |
| Сверху по центру | Очки текущего уровня; короткий +100/+50 | При результате контакта |
| Под очками с L3 | Направление/сила игрового ветра | Плавное состояние симуляции |
| Сверху справа | Пауза и три отметки ошибок + «0/3» | При завершённом выстреле |
| Слева над пальцем | Сердце, «Пульс 72», короткий ECG | Фаза та же, что у sway |
| Под пульсом | Лёгкие, «Концентрация», шкала ресурса | Удержание/восстановление |
| Снизу по центру | «Капсулы 08/18», цели 2/5 | На выстреле / успехе |
| Справа над выстрелом | Кнопка входа/выхода из прицела | Toggle |
| Справа снизу | Большая кнопка выстрела | Один pointer-down — один выстрел |
| Слева под пульсом и дыханием | Кнопка задержки дыхания | Удержание |
| Рядом справа при воде | «Протереть», круговой значок | Появляется контекстно |
| Справа у края линзы с L4 | Кратность и кнопки +/− | Только локальное увеличение; targets ≥44 px |

В учебном варианте можно использовать слово «Дыхание» со вторичной подписью «Запас концентрации». Значение шкалы — ресурс, а не фаза вдоха; это различие объясняется в обучении. Прицельная сетка — часть линзы, а не HUD поверх всего экрана. HUD в ADS не перескакивает и не увеличивается.

## 3. Управление

Наведение — drag по свободной области левой/центральной части, с отдельным pointerId. Прицел — toggle, чтобы не требовать одновременно четыре удержания. Задержка дыхания — hold слева; стрелять можно отдельным пальцем. На маленьких телефонах альтернативный режим «нажать для концентрации на 2 секунды», доступный в настройках. Чувствительность ADS снижается с ростом увеличения так, чтобы короткий drag не перескакивал всю цель; отдельная настройка, инверсия оси отключена по умолчанию.

Касание UI не вращает камеру. `pointercancel`, потеря фокуса, отпускание вне canvas прекращают задержку и сбрасывают захваченные указатели. Нажатие «Пауза» в любой фазе не стреляет. После закрытия модалки первый tap не проваливается в выстрел. Леворукий режим зеркалит touch-controls и закреплённые карточки; сами мир и оптика не зеркалятся. Мышь: drag/движение по выбранному режиму, ПКМ ADS, ЛКМ выстрел, Shift концентрация, Esc пауза.

## 4. Полный перечень экранов

| ID | Экран | Основные действия / исключения |
|---|---|---|
| S00 | Загрузка | Прогресс реальных assets, retry без потери прогресса |
| S01 | Главное меню | Играть, тренировка, уровни, настройки, выход в QuRa |
| S02 | Выбор уровня | 9 карточек, комплект, дистанция, лучший результат, замок |
| S03 | Карточка уровня | Локация, новая механика, состав, старт, назад |
| S04 | Обучение | Мишень под платформой, прицел, дыхание, безопасный спуск |
| S05 | Обычный вид | Основной HUD, оружие в руках |
| S06 | Прицеливание | Только локальное увеличение линзы |
| S07 | Полёт | Патрон списан, повторный огонь заблокирован |
| S08 | Успех | Короткая обратная связь без модального окна |
| S09 | Ошибка/курочка | Одна отметка, причина, реакция и возврат |
| S10 | Переход раунда | «Раунд 3/5», новая героиня, 1–1.5 с |
| S11 | Пауза | Продолжить, начать уровень заново, настройки, выйти |
| S12 | Результат победы | Очки, точность, центры, ошибки, улучшение, далее |
| S13 | Результат поражения | Точная причина, повтор, выбор уровня |
| S14 | Настройки | Звук, чувствительность, левша, тряска, качество, язык |
| S15 | Портретная ориентация | Пауза, просьба повернуть телефон, выход |
| S16 | Потеря контекста/сети | Восстановить, повторить загрузку, безопасный выход |
| S17 | Выход с незавершённым уровнем | Подтверждение только потери текущей попытки |

Все кнопки имеют default/pressed/disabled/focus. Disabled-выстрел при cooldown визуально коротко заполняется по кругу, но не превращается в навязчивую игровую шкалу. Недостаток ресурса объясняется рядом с лёгкими, не общей ошибкой приложения. При завершённом уровне отсутствует скрытая обязательная рекламная пауза.

## 5. Микротексты

«Цель — мишень под платформой»; «Удерживайте, чтобы задержать дыхание»; «Дайте дыханию восстановиться»; «Капсулы закончились»; «В мишень, а не в курочку»; «Курочка в безопасности»; «Раунд пройден»; «Открыт новый комплект»; «Поверните телефон горизонтально».

Локализация RU+EN: все строки по ключам, числа форматируются отдельно. Не запекать русские подписи в текстуры дерева, кнопок или видео. Английские строки могут занимать больше места; проверить переполнение. Не скрывать ошибки только цветом, звук не является единственным объяснением события.
