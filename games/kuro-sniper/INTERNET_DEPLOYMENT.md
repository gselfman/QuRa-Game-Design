# QuRa. Снайпер — публикация в интернете

Дата: 16.11.2026. Версия: 0.4.3.

Играть: **https://gselfman.github.io/QuRa-Game-Design/sniper/**

Игра работает по HTTPS на GitHub Pages, локальный сервер и установка не нужны. Доступ публичный. Данные XP, сундуков, рекордов и настроек сохраняются отдельно в браузере каждого устройства. Аккаунты QuRa и общий серверный рейтинг не подключены.

## Исходники и обновление

Игровые исходники: `prototypes/kuro-sniper`, ветка `codex/kuro-sniper-prototype-v01`. Проверенный исходный коммит: `fc27c6a870d1bff5a60336e88ceada512ad7b895`.

Workflow `.github/workflows/pages.yml` находится также в main. Он автоматически запускается при изменении исходников прототипа в рабочей ветке, выполняет `npm ci`, 24 проверки правил, TypeScript и Vite-сборку с базой `/QuRa-Game-Design/sniper/`. Затем публикует `/sniper/` вместе с прежним содержимым Arena из main. Для повторной публикации можно вручную запустить этот workflow в GitHub Actions. Откат — вернуть нужную версию исходников и повторить публикацию.

GitHub Pages настроен на workflow-сборку с HTTPS. Окружение github-pages допускает только main и точную ветку `codex/kuro-sniper-prototype-v01`; публикация из произвольных веток не включена.

Успешная публикация: https://github.com/gselfman/QuRa-Game-Design/actions/runs/43862561490 (коммит workflow main: `2868c5626a979ebd42dfaeb71b2bb08d2f1f3244`). Ранний запуск из рабочей ветки был отклонён автоматически созданным ограничением окружения; после этого добавлено точечное разрешение для рабочей ветки.

## Проверка опубликованной игры

Проверка выполнена в Chrome на Mac по настоящему внешнему HTTPS-адресу, без локального прокси. Проверены название, обычный запуск без QA-инструментов, реальный выстрел (17 патронов, 10 очков), 226 запросов к ресурсам и все десять уровней. Для уровней 2–10 проверена неоднородность реального буфера линзы (SD красного канала 41.76–60.21); первый уровень использует коллиматор без отдельного оптического буфера. Ошибок страницы, ответов HTTP 4xx/5xx и неудавшихся запросов не обнаружено. QA-переключатель используется только для воспроизводимой проверки уровней и отсутствует в обычном запуске.
