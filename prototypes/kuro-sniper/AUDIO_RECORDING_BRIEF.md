# QuRa. Снайпер — звуки винтовок

16.11.2026. Название проекта на экранах: **QuRa. Снайпер**. `kuro-sniper` остаётся техническим идентификатором папки.

Это конкретные звуковые ориентиры для художника по звуку. Текущие пять 3D-моделей вымышленные и не являются точными моделями перечисленных марок. Стрельба — безопасная игровая условность; реальные баллистические параметры не копируются.

| Уровень | Дистанция | Звуковой ориентир | Ключ набора |
|---|---:|---|---|
| 1 | 10 м | ИЖ-38, пружинная воздушка | `airgun_izh38` |
| 2 | 25 м | Мосин 1891/30 | `mosin_9130` |
| 3 | 50 м | Anschütz 1903 | `anschutz_1903` |
| 4 | 100 м | Anschütz 1903, та же винтовка | `anschutz_1903` |
| 5 | 200 м | Remington 700 | `remington_700` |
| 6 | 350 м | Remington 700, тот же набор | `remington_700` |
| 7 | 500 м | Accuracy International AWM | `ai_awm` |
| 8 | 750 м | Accuracy International AWM, тот же набор | `ai_awm` |
| 9 | 1000 м | Barrett MRAD | `barrett_mrad` |
| 10 | 1000 м | Barrett MRAD, тот же набор | `barrett_mrad` |

Нужны шесть наборов. Для каждого желательно отдельно: `fire` — один выстрел; `boltOpen` — отпирание/открытие механизма; `boltClose` — закрытие; `casing` — падение гильзы. У воздушки гильзы нет, вместо затвора — короткая механика заряжания. Не склеивать выстрел и затвор в один файл: игра синхронизирует механику с анимацией. Можно начать только с шести файлов `fire`, остальные слои пока останутся синтезированными.

**Поставка:** WAV, mono, 48 кГц, предпочтительно24 bit;44.1 кГц/16 bit тоже декодируется. Оставить естественный хвост, убрать щелчки на границах и длинную тишину до атаки. Пик до−1 dBFS, без клиппинга. Предпочтительно сухая запись без сильного комнатного эха: сарай/поле будут сводиться отдельно. Хорошо иметь3 варианта каждого выстрела для дальнейшего разнообразия; первый этап использует один выбранный вариант.

Файлы кладутся в `public/assets/audio/weapons/` исходников; в готовой сборке это `dist/assets/audio/weapons/`. Можно передать WAV владельцу текущего рабочего чата для подключения. Имена, например `mosin_9130-fire.wav`, `mosin_9130-boltOpen.wav`, `mosin_9130-boltClose.wav`, `mosin_9130-casing.wav`. Подключение через `manifest.json`:

```json
{"formatVersion":1,"weapons":{"mosin_9130":{"fire":"mosin_9130-fire.wav","boltOpen":"mosin_9130-boltOpen.wav","boltClose":"mosin_9130-boltClose.wav","casing":"mosin_9130-casing.wav"}}}
```

До получения файлов `weapons` пуст: игра использует шесть прежних синтезированных профилей. Отсутствующие слои остаются синтезированными; файл с выстрелом заменяет только слой выстрела. Характерные механика и гильза второй винтовки не теряются. Громкость управляется общим миксом и лимитером. Производство звука может выполняться нейросетью или из подготовленных владельцем лицензированных записей; конкретный платный сервис не обязателен.

Первичные справочные страницы для написания названий: [ANSCHÜTZ — руководства, включая1903](https://www.anschuetz-sport.com/en/downloads/bedienungsanleitungen/), [Remington Model700](https://remington-arms.com/700-series/), [Barrett MRAD](https://barrett.net/products/mrad/). Эти ссылки — справка по моделям, а не источник готовых звуков.
