# Куро Снайпер — запускаемый прототип v0.1

QuRa / Кура. Горизонтальная браузерная игра для смартфона и компьютера. Ветка игрового дизайна: `codex/kuro-sniper-prototype-v01` в `gselfman/QuRa-Game-Design`.

## Быстрый запуск готовой сборки на Mac

Распаковать архив и дважды нажать **Играть.command**. Откроется браузер с игрой. Python3 нужен для локального сервера, Node.js для готовой сборки не требуется. Окно запуска оставить открытым; закрытие окна/нажатие Ctrl+C останавливает сервер. Сервер слушает только `127.0.0.1`, не открывает компьютер в локальную сеть или интернет.

Альтернативная команда из каталога прототипа: `python3 tools/serve.py --open`.

HTML нужно открывать через этот сервер, а не как `file://`: браузер загружает 3D-модели и текстуры отдельными запросами. В готовом архиве есть `dist/`; при клонировании GitHub сначала собрать из исходников.

## Работа с исходниками

```sh
npm ci
npm run dev
```

Сборка: `npm run build`. Проверки правил: `npm test`.

## Управление

- Смартфон: горизонтально; тянуть изображение для наведения; слева — прицел, справа — выстрел и удержание дыхания; у поздних прицелов +/− меняют увеличение, при каплях появляется «Протереть».
- Компьютер: тянуть мышью для наведения; ПКМ или Q — прицел; Пробел или кнопка — выстрел; Shift — удержать дыхание; Esc — пауза. Стрелки дают мелкую корректировку.
- Диск под платформой — успех. Курочка — одна ошибка и −100 очков, безопасный взлёт и возврат. Третья ошибка завершает уровень. В тренировке число ошибок не ограничено.

## Что работает

Девять дистанций 10–1000 м, 45 раундов, пять канонических персонажей; пять Blender-моделей оружия и один механизм платформы. Звон/складывание/спуск, безопасные штрафы и перья, прогулка внизу. Пульс и дыхание влияют на наведение; Дурочка двигает диск, Профессор меняет траекторию, Боевик заливает стекло, Гламурочка повышает напряжение. Ветер с третьей дистанции. Результаты, точность, центры, звёзды, локальные рекорды, настройки звука/чувствительности/графики/левши.

Оптика — вторая камера той же сцены и отдельная текстура внутри круглой линзы. Вне линзы фон не увеличивается. Коллиматор первого уровня 1× сохраняет масштаб мира.

## Границы версии

Персонажи используют оригинальные QuRa-изображения в **2.5D**, с процедурным движением и сменой утверждённых поз. Это сохраняет внешность; полноценные новые 3D-rig и скелетная анимация героинь ещё не произведены. Оружие, платформы и окружение — 3D. Окружение и эффекты прототипные, баланс предварительный. Нет серверной интеграции, GE/XP, платежей и выдачи аккаунтных наград. Рекорды хранятся только в браузере.

Chrome на Mac и мобильная компоновка 844×390 проверены, включая одновременное наведение/дыхание/выстрел через touch-события. Это не подтверждение FPS на настоящих iPhone/Android или совместимости Safari. Фактические результаты: `qa/browser-report.json`, `qa/optics-report.json`, `qa/desktop-mobile-viewport-performance.json`.

## Состав

`src/game.mjs` — воспроизводимые правила/траектории; `src/world.ts` — сцена, оружие, камеры и визуальные реакции; `src/main.ts` — управление/HUD/меню; `src/audio.ts` — синтез звуков без внешнего аудиосервиса. `public/assets/characters` — исходные QuRa-позы, `public/assets/models` — экспортированные модели. Blender-источники воспроизводятся `tools/build_models.py`. `tests/game.test.mjs` — десять тестов правил, `tools/browser-qa.mjs` — браузерный проход.

Режим `?qa=1` включает явные тестовые инструменты для воспроизводимой проверки, без него они отсутствуют. В браузерном проходе эффекты заморожены при проверке всей кампании; их отдельные расчёты проверены unit tests. Автоматический проход не заменяет тестирование баланса людьми.

Персонажная графика — материалы проекта QuRa; в этом прототипе она не генерировалась заново. Оружие и платформа процедурно созданы в Blender. Onest — SIL Open Font License, текст лицензии рядом со шрифтами. Babylon.js — Apache-2.0, зависимости закреплены package-lock.

По решению владельца прототип оставлен **локально и в GitHub**. Публикация/отправка исходников в новое хранилище Sites не разрешена; размещение в интернете этой поставкой не производится.
