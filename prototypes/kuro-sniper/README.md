# QuRa. Снайпер — запускаемый прототип v0.4.3

QuRa. Снайпер. Горизонтальная браузерная игра для смартфона и компьютера. Ветка игрового дизайна: `codex/kuro-sniper-prototype-v01` в `gselfman/QuRa-Game-Design`.

## Интернет-версия

Публичный адрес: https://gselfman.github.io/QuRa-Game-Design/sniper/

Игра загружается с GitHub Pages без локального сервера. Рекорды, XP, сундуки и настройки остаются в браузере конкретного устройства; синхронизации между компьютерами и аккаунтных наград нет.

Сборка для этого адреса: `npm run build -- --base=/QuRa-Game-Design/sniper/`. Все запросы к текстурам, моделям, слоям персонажей и аудио используют Vite BASE_URL через `src/asset-url.ts`. Локальная сборка `npm run build` по-прежнему работает от корня сервера. Публичная сборка отличается метаданными `mode: public-demo`, `hosting: github-pages`; игровая логика та же.

Публикация: `.github/workflows/pages.yml` в репозитории. Исходники игры берутся из `codex/kuro-sniper-prototype-v01`, существующие Arena-маршруты — из main. Обновления папки прототипа в этой ветке запускают проверку, сборку и публикацию. Ручной повтор — GitHub Actions → Deploy QuRa prototypes to GitHub Pages → Run workflow. Предыдущий выпуск можно восстановить откатом исходников в ветке и повторным запуском публикации.

Проверка развёрнутой игры на Mac: `KS_QA_URL=https://gselfman.github.io/QuRa-Game-Design/sniper/ KS_QA_REPORT=qa/v043-hosting-live.json node tools/hosting-qa.mjs`. Проверяется обычный запуск без QA-инструментов, выстрел, ресурсы и отрисовка линзы на всех десяти уровнях.

## Быстрый запуск готовой сборки на Mac

Распаковать архив и дважды нажать **Играть.command**. Откроется браузер с игрой. Python3 нужен для локального сервера, Node.js для готовой сборки не требуется. Окно запуска оставить открытым; закрытие окна/нажатие Ctrl+C останавливает сервер. Сервер слушает только `127.0.0.1`, не открывает компьютер в локальную сеть или интернет.

Альтернативная команда из каталога прототипа: `python3 tools/serve.py --open`.

HTML нужно открывать через этот сервер, а не как `file://`: браузер загружает 3D-модели и текстуры отдельными запросами. В готовом архиве есть `dist/`; при клонировании GitHub сначала собрать из исходников.

## Управление

- Смартфон: горизонтально; тянуть изображение для наведения; слева под пульсом — удержание дыхания, справа — выстрел и переключатель прицела над ним; у поздних прицелов +/− меняют увеличение, при каплях появляется «Протереть».
- Компьютер: тянуть мышью для наведения; ПКМ или Q — прицел; Пробел или кнопка — выстрел; Shift — удержать дыхание; F — вернуть обзор двора; Esc — пауза. Стрелки дают мелкую корректировку.
- Диск под платформой — успех. Курочка — одна ошибка и −100 очков, безопасный взлёт и возврат. Третья ошибка завершает уровень. В тренировке число ошибок не ограничено.

## Что работает

Девять основных дистанций 10–1000 м и десятый финал с движущимися шариками; всего 46 раундов, пять канонических персонажей; пять Blender-моделей оружия и один механизм платформы. Звон/складывание/спуск, безопасные штрафы и перья, прогулка внизу. Пульс и дыхание влияют на наведение; Дурочка двигает диск, Профессор меняет траекторию, Боевик заливает стекло, Гламурочка повышает напряжение. Ветер с третьей дистанции. Результаты, точность, центры, звёзды, локальные рекорды, настройки звука/чувствительности/графики/левши.

Оптика — вторая камера той же сцены и отдельная текстура внутри круглой линзы. Вне линзы фон не увеличивается. Коллиматор первого уровня 1× сохраняет масштаб мира.

## Границы версии

Персонажи используют оригинальные QuRa-изображения в **2.5D**, с 65 исходными слоями тела/одежды, независимыми движениями головы, крыльев и лап и сменой утверждённых поз. Это сохраняет внешность; полноценные новые 3D-rig и скелетная анимация героинь ещё не произведены. Оружие, платформы и окружение — 3D. Окружение и эффекты прототипные, баланс предварительный. Нет серверной интеграции, GE/XP, платежей и выдачи аккаунтных наград. Рекорды хранятся только в браузере.

Chrome на Mac и мобильная компоновка 844×390 проверены, включая одновременное наведение/дыхание/выстрел через touch-события. Это не подтверждение FPS на настоящих iPhone/Android или совместимости Safari. Фактические результаты: `qa/browser-report.json`, `qa/optics-report.json`, `qa/desktop-mobile-viewport-performance.json`.

## Состав

`src/game.mjs` — воспроизводимые правила/траектории; `src/world.ts` — сцена, оружие, камеры и визуальные реакции; `src/main.ts` — управление/HUD/меню; `src/audio.ts` — шесть синтезированных профилей оружия, механика, гильзы и локальное каноническое кудахтанье. `public/assets/characters` — исходные QuRa-позы, `public/assets/models` — экспортированные модели. Blender-источники воспроизводятся `tools/build_models.py`. `tests/game.test.mjs` — 24 теста правил, `tools/browser-qa.mjs` — браузерный проход.

Режим `?qa=1` включает явные тестовые инструменты для воспроизводимой проверки, без него они отсутствуют. В браузерном проходе эффекты заморожены при проверке всей кампании; их отдельные расчёты проверены unit tests. Автоматический проход не заменяет тестирование баланса людьми.

Персонажная графика — материалы проекта QuRa; в этом прототипе она не генерировалась заново. Оружие и платформа процедурно созданы в Blender. Onest — SIL Open Font License, текст лицензии рядом со шрифтами. Babylon.js — Apache-2.0, зависимости закреплены package-lock.

По решению владельца прототип оставлен **локально и в GitHub**. Публикация/отправка исходников в новое хранилище Sites не разрешена; размещение в интернете этой поставкой не производится.

Полевая запись каждого типа оружия, реалистичные модели деревьев/строений и полный3D персонажей остаются следующим художественным этапом.

Проверки новой версии: `qa/v02-browser-report.json`, `qa/v02-audio-report.json`. Обновлённая библия: `games/kuro-sniper/VISUAL_AUDIO_V02.md` в корне репозитория. ## Текстуры по референсу и дальняя оптика, v0.2.1

Матовые состаренные доски (`weathered_brown_planks`), потёртый дощатый пол (`old_wood_floor`), тканевый навес с геометрическими складками и тёплые лампы. Травяное покрытие, карточки травы/ромашек и подробный дальний лесной фон созданы встроенным ImageGen по контакту с референсом владельца и подключены в игру; персонажные слои QuRa сохранены. Это материалы и дальняя декорация сцены, игровое действие остаётся3D с двумя камерами.

Ассеты: `public/assets/foliage/meadow-flowers-v1.png`, `public/assets/materials/meadow-albedo-v1.png`, `public/assets/materials/woodland-panorama-v1.png`. Промпты: `VISUAL_ASSET_PROMPTS_V021.json`, `GRASS_ALBEDO_PROMPT_V021.txt`. Лесной фон — детальная плоская декорация для неподвижной позиции стрелка, свободного обхода камерой нет; соответствие художественному референсу остаётся предметом визуальной приёмки. Карты микро-рельефа травы приблизительные, не получены измерением нового albedo.

Исправлена ошибка Retina: прежнее `max(1,DPR/1.5)` уменьшало backbuffer ниже размера CSS; теперь используется `1/min(DPR,1.5)`. Картинка на Retina получает больше пикселей. В облегчённом режиме разрешение соответствует CSS, а персонажи используют плоские позы. Разрешение линзы выбирается по её размеру и плотности экрана, до1536². Сухая линза полностью удаляет слой размытия.

L9 стартует с144×, L10 с64× для поиска бегущих целей; максимальное увеличение финальной винтовки192×. Игровая кратность условная. Если в дальней линзе нет ни одной незакрытой цели, появляется стрелка направления, которая не наводит оружие автоматически. Периферия сохраняет исходный масштаб. Проверка: `node tools/long-range-qa.mjs` и `qa/v021-long-range-report.json`.

Детализированные деревья за мишенями: `public/assets/foliage/oak-v1.png`; промпт `TREE_PROMPT_V021.txt`. Использованы alpha-test карточки с реальными3D-позициями, а не полигональные кроны.

## v0.4.1 — независимая отрисовка прицела

Оптический проход больше не читает предыдущий список видимых объектов основной камеры: он строится из живой сцены. Буфер и его подключение пересоздаются после resize и восстановления графики. В неактивном поле шейдер не вычисляет искажение. Регрессия: `tools/scope-render-qa.mjs`, доказательство старого однотонного кадра и итоговый отчёт в `qa/v041-*`. Подробности — `games/kuro-sniper/OPTICS_RENDER_FIX_V041.md` в репозитории.
