# Проверка прототипа v0.1

15.11.2026. Запуск на Mac Apple M2, Chrome headless; mobile viewport844×390 — эмуляция, не настоящий телефон.

## PASS

- TypeScript и production build Vite.
- 10 unit tests: все9 уровней/135 попаданий, очки/патроны/штрафы, повторное событие, пауза, задержка дыхания/восстановление, cooldown, обучение, разные области курочки/диска, FOV, замороженное воздействие ветра/поля на выстрел.
- Браузер: все45 раундов девяти уровней через реальную интеграцию капсулы и интерфейс выстрела; в каждой попытке15 успехов,3 капсулы в остатке и3050 очков. Seed/ветер/sway заморожены только в тестовом режиме для воспроизводимости.
- Браузер: поражение на третьем промахе; пауза замораживает время; удержание/отпускание дыхания; протирка убирает воду.
- Три одновременных реальных touch-контакта в Chrome emulation: задержка дыхания, drag наведения, выстрел. Расходуется одна капсула, отпускание снимает задержку.
- Поворот в портрет показывает предложение развернуть телефон и ставит на паузу.
- Ошибки JS и HTTP при полном прогоне: 0.
- Сравнение изображений: фрагмент периферии до/после ADS совпадает попиксельно; маска2× прицела увеличивает диск примерно16→34 px (пороговая оценка с погрешностью антиалиасинга). Геометрическая калибровка FOV проверена отдельно точным unit test.
- Кадр с5 героинями и двумя камерами: p50≈16.7мс, p95≈17.7мс, engine≈59.9fps на этом Mac/Chrome. Это не мобильный benchmark.
- Готовая сборка `dist/` запущена через пользовательский `Играть.command`/Python-сервер:HTTP200, первый обычный выстрел без QA-инструментов дал100 очков,17 капсул и переход во второй раунд; ошибок JS нет. Отчёт `qa/packaged-build-report.json`.
- Визуально просмотрены меню, обычный вид, оптика, вода, посадка, горизонтальный мобильный экран. Исправлены ориентация текстур, aspect оптики и регистрация лап на платформе.

## NOT RUN / ограничения

Safari/iOS и физический Android/iPhone; долгий thermal-тест; 3D-skeletal персонажи; серверная QuRa-интеграция и награды. Реальная экономика и production QuRa не изменялись. Публикация Sites отклонена владельцем; внешнего игрового размещения нет.

Анимация героинь сейчас процедурная2.5D, а не завершённая объёмная модель. Окружение — рабочая игровая сцена, не финальная художественная приёмка. Траектория условная игровая: ветер/локальное поле и время полёта; реальные таблицы оружия не используются.
