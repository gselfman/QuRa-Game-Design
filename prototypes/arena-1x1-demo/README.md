# Демо боя Арены 1×1

Живая версия: https://claude.ai/artifact/2MgK3WkqX964am4atrV66f
Открыть локально: `python3 -m http.server` в этой папке.

- Движок — копия `tools/arena-engine.mjs` (числа без изменений), встроен в `index.html`.
- Сцена — утверждённые слои ARN01 (`arena/`), значки ARN02 (`ui/`), эффекты FX01 (`fx/`), курочки — временные картинки из кошелька (`img/`), заменить на CARD v12.
- Режимы: тренировка с ботом (equilibrium), случайный соперник (тактики защиты), вдвоём на телефоне.
- Источник для Шага 5 интерфейса v2 в `gselfman/QuRa` (`docs/product/GAME_UI_V2.md` §8).
