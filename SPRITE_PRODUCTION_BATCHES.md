# QuRa — Sprite Production Batches v1

**Статус:** готовые постановки для последовательной генерации листов и последующей загрузки в Figma.
**Область:** единая 2D/soft-3D графика QuRa, Курятник, Arena, награды и общие мини-игры.
**Важно:** это **новая библиотека**, не замена уже утверждённым игровым спрайтам «Волка». Не перегенерировать существующие листы без сверки с Figma.

## Общий мастер-промпт для каждого листа

> Generate ONE professionally consistent asset sprite sheet for QuRa game containing exactly 25 distinct objects as a 5 columns × 5 rows orthogonal grid. Every cell holds exactly ONE complete object corresponding to the numbered specification, left-to-right and top-to-bottom. Cozy premium 3D game UI style, soft physically plausible volumes, warm wood, amber and polished gold, soft key light from upper left, consistent camera angle approximately 3/4 front, precise materials, readable silhouettes, crisp edges, clean transparent alpha background. No words, no labels, no numbers, no watermark, no scenery, no cell borders, no shadows crossing cells. All objects fully contained with 12% inner safe margins; no overlap and no cropped objects. Equal cell widths and heights, uniform visual scale for matching object families, no duplicates. Output as high-resolution 4096×4096 PNG sprite sheet (or highest supported square resolution; upscale without changing grid), transparent background.

**Негативные условия:** cartoon-flat, random style, painterly blur, photorealistic packaging, text, letters, fake logos, extra props, cut edges, intersecting cells, opaque backgrounds, inconsistent lighting, repeated items.

**Важно для генерации:** вместе с мастер-промптом подставить *только один* список 25 позиций соответствующего листа. Различимые состояния одного объекта делаем отдельными ячейками. Если модель не соблюла 5×5, лист не принят.

## Технический контракт

- Один лист = ровно **25** объектов, координаты по сетке: column 1..5, row 1..5.
- ID ассета: `Sxx_01` ... `Sxx_25`, экспорт: `qura_sxx_01_slug_v01.png`.
- Рекомендуемое исходное разрешение 4096², размер ячейки 819.2 px; для автоматической нарезки использовать реальный размер изображения / 5, а не фиксировать 819 px.
- Отступ от краёв ячейки минимум 12%; для эффектов допустима прозрачная область, но ни один объект не пересекает соседний слот.
- Figma: page `QuRa Assets` → section `Sxx — <название>`, слой `source_sheet`, 25 компонентов по ID после ручной проверки.
- Статус по каждому: planned → generated → uploaded → sliced → QA-approved → used-in-screen.
- Игровые характеристики и экономика не должны быть вписаны в картинку; цифры/надписи всегда UI-слоя.
- Для комплектов персонажей, экипировки и анимаций по кадрам используются отдельные пакеты, не этот универсальный лист.
- Стараться генерировать 1 лист за раз, проверять целостность и только затем загружать в Figma.
